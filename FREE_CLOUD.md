# Бесплатный запуск без ноутбука

Код хранится на GitHub, а бот работает на серверах Google Apps Script.
Он проверяет Telegram примерно раз в минуту. Это относится к каждому действию:
выбор даты, пары, студентов и подтверждение. Ноутбук после переноса можно выключить.
Apps Script выполняет код JavaScript, поэтому здесь используется облачная версия
из `google/Telegram.gs`; Python-версия остаётся для локального запуска.

## Подготовка Google-проекта

1. Открой вашу таблицу → «Расширения» → «Apps Script».
2. Сохрани исходный код проекта перед заменой. Замени содержимое `Код.gs` кодом
   из пяти файлов в этом порядке: `Attendance.gs`, `Headers.gs`, `Clear.gs`,
   `Batch.gs`, `Telegram.gs`. В архиве также есть готовый объединённый `google/CloudBot.gs`.
   Используй либо объединённый файл, либо пять отдельных — одновременно не добавляй.
3. Нажми «Сохранить проект». Имеющиеся свойства подключения таблицы сохранятся.
   Если это новый проект, сначала выполни `configure`, как описано в `google/SETUP.md`.
4. Выбери `configureCloudBot` и нажми «Выполнить». Google запросит разрешения
   на таблицы, обращения к внешним сервисам и создание запуска по таймеру.
   Разрешения выдаёт твой Google-аккаунт, который уже может редактировать таблицу.
5. Вернись во вкладку таблицы: там появится окно ввода токена @Schedule3112bot.
   Токен берётся из BotFather и сохраняется в свойствах скрипта, а не в исходном коде.
   Не публикуй токен или свойства на GitHub. У редакторов общего проекта может
   быть доступ к коду и свойствам — используй проект с доверенными редакторами.
6. Выполни `checkCloudBot`. В журнале должны появиться имя бота, дата, число пар
   и студентов, `attendanceChanged:false`. Эта проверка не пишет отметки и не
   получает новые сообщения Telegram.

Новый URL веб-приложения для облачного запуска не нужен. Триггер выполняет
последний сохранённый код. Уже опубликованная версия при этом не меняется.

## Переключение с ноутбука

Одновременно сообщения должен получать только один экземпляр бота.

1. Заверши текущую запись в боте или нажми «Отмена».
2. Останови локальную Python-версию и убедись, что процесс завершился.
3. Для сохранения уже обработанных сообщений перенеси из локального `state.json`
   значение `offset` в свойство Google-проекта `TG_OFFSET`. При переносе
   ответственных перенеси привязки из `identities` в свойства `TG_ID_<username>`
   (имена в нижнем регистре). Проверь структуру `state.json`: числовой ID пользователя
   должен стать строковым значением свойства. Эти данные не публикуются на GitHub.
   Незавершённые диалоги локальной версии не переносятся; после переключения `/start`.
4. Выбери `enableCloudBot` и выполни. Создастся один триггер `pollTelegram`
   с интервалом в одну минуту. Не запускай локальную версию после этого.
5. Выполни `cloudBotStatus`: `enabled:true`, `triggers:1`.
   После первой проверки появится `lastPoll` с временем последнего обращения.
6. Отправь боту `/start` и дождись ответа. Проверь выбор даты. Теперь ноутбук
   можно выключить: расписание и отметки обрабатываются Google.

Выбранные студенты и этап диалога сохраняются в свойствах скрипта между
минутными запусками. Б/Н/З, объяснительная, лимит трёх дней З, выбор нескольких
студентов, подтверждение и удаление отдельной отметки поддерживаются.
Медицинские справки и подписанные заявления проверяет ответственный человек.

## Остановка и исправление проблем

- `disableCloudBot` выключает обработку и удаляет её триггер. После этого можно
  снова запустить Python на ноутбуке. Чтобы не обработать старые сообщения повторно,
  перенеси последнее `TG_OFFSET` обратно в `offset` локального `state.json`.
- Если ответов нет, открой «Количество выполнений», проверь ошибки `pollTelegram`
  и выполни `cloudBotStatus`. Не публикуй секреты и содержимое свойств при обращении
  за помощью.
- Ошибка «Работает другая копия бота» означает конфликт запуска. Останови вторую копию.
- Если сайт ещё не опубликовал нужную дату, бот сообщает об этом и не подставляет
  старое расписание другого года.
- Google ограничивает число запросов, время выполнения триггеров и объём свойств.
  Бесплатный вариант рассчитан на небольшую группу и не гарантирует точный момент
  ответа. При исчерпании квот выполнение может приостанавливаться.
