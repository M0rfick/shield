# Telegram: расписание и пропуски группы 26290911/3112

Локальная версия написана на Python 3.9+ и использует только стандартную библиотеку.
Для бесплатной работы без ноутбука есть облачная версия на JavaScript в Google
Apps Script: [FREE_CLOUD.md](FREE_CLOUD.md). Она принимает команды напрямую из
Telegram; минутный таймер остаётся резервным вариантом. Действия с расписанием
и посещаемостью сохраняются.
Расписание берётся с https://polytech-shedule.ru. Можно выбрать дату с днём недели,
сегодня, завтра и подгруппу. Бот показывает только выбранный день.

## Пропуски

Нажми «Отметить пропуск» или отправь `Фамилия Имя — не был`.
Далее выбери дату, предмет и пару, студента кнопкой и основание. Фамилии берутся
из списка выбранного месяца в Google Таблице. Есть поиск и перелистывание.
Перед записью бот покажет ФИО, предмет,
отметку и ячейку Google Таблицы. Запись происходит после подтверждения.

На одной паре можно выбрать сразу несколько студентов: в списке фамилий нажми
«Выбрать нескольких», отметь фамилии, затем «Выбрать причину». Галочка показывает
выбор; повторное нажатие снимает его. Поиск и перелистывание сохраняют выбранных
студентов. Общая категория применяется к показанному списку после одного
подтверждения. Для разных причин повтори выбор на этой же паре с другим списком.
Выбор одного студента работает как раньше; есть кнопка «Выбирать по одному».
Справки и заявления нужно подтвердить для каждого выбранного студента.
Лимит З проверяется индивидуально. Если хотя бы один студент не проходит проверку,
до исправления отметки всей выбранной группе не записываются.

- Н — без уважительной причины.
- Б — после подтверждения, что справка проверена и размещена в чате по шаблону.
- З — после подтверждения заявления в чате с подписью Назарова; максимум три разных дня в месяц.
- О — записывается как Н; как З только после подтверждения согласования с куратором.

Бот не проверяет подлинность медицинских документов. Ответственный подтверждает проверку.
Для нескольких пар одного дня лимит З учитывает один день.
Доступ определяется по Telegram-именам; отправлять числовые ID не нужно.
Telegram-имя автоматически связывается с аккаунтом при первом обращении.

Чтобы удалить ошибочную отметку, нажми «Убрать отметку» (или `/clear`), выбери
дату, пару и студента. Бот покажет текущую отметку и точную ячейку. Нажми
«Подтвердить удаление». Очищается только выбранная отметка; предметы, форматирование
и другие студенты сохраняются. Пары для удаления берутся из таблицы, поэтому
исправление прошлых дат не зависит от доступности старого расписания на сайте.
Если кто-то изменил отметку после просмотра, бот попросит выбрать её заново.

## Запуск

1. Установи Python с https://www.python.org/downloads/ и распакуй архив.
2. Скопируй `.env.example` в `.env`. Заполни токен и параметры подключения Google.
   Инструкция: [google/SETUP.md](google/SETUP.md).
3. Открой `start.bat` на Windows или `start.command` на Mac.
   Альтернатива: `python3 -u bot.py`. Токен нужно указать в настройках перед запуском.
4. Открой бота в Telegram и отправь `/start`.

Компьютер или сервер должен оставаться включённым. Google Таблица работает онлайн,
а программа бота принимает сообщения Telegram и передаёт отметки в неё.
Одновременно должна работать только одна копия бота.
Секреты в `.env`, `state.json` и журналы нельзя публиковать на GitHub.

Основной бесплатный вариант: [FREE_CLOUD.md](FREE_CLOUD.md).
Для отдельного платного сервера подготовлен `Dockerfile` и сохранение настроек на
постоянном диске: [CLOUD.md](CLOUD.md). Сам GitHub хранит код;
сообщения обрабатывает Google Apps Script либо отдельно запущенный сервер.

## Расписание на неделю

`/week` или кнопка «Вся неделя» присылает текущую неделю с понедельника по
воскресенье одним сообщением, с учётом выбранной подгруппы. Для другой недели:
`/week 05.10.2026`. Предметы, преподаватели и аудитории сгруппированы по датам.
Если полный список превышает лимит Telegram, бот отправляет его одним текстовым
файлом, сохраняя все пары; на несколько сообщений расписание не разбивается.

## Команды

`/date`, `/date 05.10.2026`, `/today`, `/tomorrow`, `/week`, `/week 05.10.2026`, `/subgroup`, `/miss`, `/clear`, `/cancel`, `/refresh`.
Кнопка «Обновить» очищает кеш сайта. Обычный кеш действует до двух минут.
Если расписание не опубликовано, бот сообщает об этом и не использует даты другого года.

## Проверка

```sh
python3 -m unittest -v
python3 bot.py --preview 05.10.2026
node google/telegram.test.js
node google/receiver.test.js
node google/placement.test.js
```

На Windows вместо `python3` можно использовать `py -3`.
Автоматические проверки не меняют реальную таблицу.
Предварительный результат Google (`prepare`) также не записывает отметки.

## Формат таблицы

Листы называются русскими названиями месяцев в нижнем регистре.
A — номер, B — ФИО, затем блоки по пять пар. Над строкой предметов должна быть строка
настоящих дат с годом. Бот проверяет соответствие предмета расписанию и сохраняет
отметку в нужную ячейку и заполняет заголовки выбранной даты предметами с сайта.
В пустой заготовке месяца добавляет строку дат по образцу сентября, сохраняя ФИО.
Если в заготовке уже есть записи, требует ручной проверки дат. Новые месячные листы
со списком группы нужно создавать заранее. Формулы не заменяет.

Официальная документация: https://core.telegram.org/bots/api
