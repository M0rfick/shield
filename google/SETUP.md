# Однократное подключение Google Таблицы

Настройку выполняет человек с правом редактирования таблицы. Другие люди смогут
читать расписание, а записи будут принимать только от указанных ответственных.

1. Подготовьте Telegram-имена участников вида `@username`. Числовые ID не нужны.
2. В нужной Google Таблице выберите **Расширения → Apps Script**.
3. Вставьте содержимое `Attendance.gs`, `Headers.gs`, `Clear.gs` и `Batch.gs` в редактор (можно в один файл) и сохраните проект.
4. В списке функций выберите `configure` и нажмите **Выполнить**.
   Google попросит авторизовать доступ скрипта к таблицам. Это действие выполняет владелец/редактор.
   Сохраните существующий код, если проект уже содержит другие функции; при конфликте имён не заменяйте его целиком.
5. В окне таблицы введите Telegram-имена через запятую. Появится ключ подключения — скопируйте его.
6. В Apps Script выберите **Развернуть → Новое развертывание → Веб-приложение**:
   выполнение от вашего имени, доступ «Все». Это делает адрес приёмника доступным из интернета;
   сам скрипт требует отдельный секрет и разрешённое Telegram-имя для любых чтений и записей.
   Содержимое таблицы и сама таблица от этого не становятся публичными.
7. Скопируйте URL, заканчивающийся на `/exec`. В локальном `.env` бота заполните:

```text
SHEETS_WEB_APP_URL=https://script.google.com/macros/s/ВАШЕ_РАЗВЕРТЫВАНИЕ/exec
SHEETS_SHARED_SECRET=КЛЮЧ_ИЗ_ШАГА_5
AUTHORIZED_USERNAMES=Ivan_Morfick,zxcWenty,Shcherbakov_23
```

8. Перезапустите Python-бота. При обновлении исходника Apps Script нужно обновлять и его развертывание.
9. Сначала выберите реальный согласованный пропуск. Бот покажет ФИО, дату, предмет, лист,
   ячейку и существующую отметку. После подтверждения проверьте эту ячейку в Google Таблице.

Файл таблицы выбирается автоматически при `configure`; его ID не нужен в исходниках GitHub.
Порядок столбцов: A — номер, B — ФИО, далее блоки по пять пар.
Строка с ФИО считается строкой предметов, непосредственно над ней должна быть строка дат.
Даты должны быть настоящими датами Google Sheets с годом, даже если визуально показано только ДД.ММ.
Название листа — русское название месяца в нижнем регистре.

«Б» доступна после подтверждения проверки справки; «З» — после подтверждения заявления
или исключения по согласованию куратора. Лимит проверяется повторно в момент записи.
При подтверждении пропуска скрипт заполняет предметы выбранной даты с сайта.
В пустой заготовке месяца создаёт строку дат по образцу сентября и сохраняет список студентов.
При наличии записей без дат требуется ручная проверка. Отметки других студентов не меняются.

Если требуется отключить подключение, удалите развертывание в Apps Script либо смените
`SHARED_SECRET` в свойствах скрипта и настройках бота. Не выкладывайте ключи в репозиторий.

Официальная документация: https://developers.google.com/apps-script/guides/web
